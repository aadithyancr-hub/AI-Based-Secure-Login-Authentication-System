# AI-Based-Secure-Login-Authentication-System
RFID &amp; Keypad-Based Multi-Factor Authentication System using LPC2129 microcontroller. Developed using Embedded C with UART communication, 4x4 Matrix Keypad, RFID Reader, LCD Interfacing, GPIO Programming, and access control logic. Implements multi-level authentication, password verification, invalid attempt tracking, real-time status monitoring.
